# Project constitution

The project owner and coding agent maintain this file together.

- Translate requirements into observable acceptance criteria before implementation.
- Work within the approved task scope and isolated workspace returned by Agent Kit.
- Use configured validation commands; record actual results, including failures.
- Preserve data and require exact-version approval for high-impact changes.
- Keep secrets out of specifications, logs, patches, and source control.
- Document assumptions and trade-offs; escalate unresolved ambiguity to the owner.
- Stop after two failed repair attempts. Never weaken tests to manufacture success.

Add project-specific engineering principles here; no language or framework is assumed.
